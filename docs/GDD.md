# 最后一座灯塔　游戏设计文档

**历史设计稿 · 版本 0.2**　2026-11-23　·　[功能索引](#feature-index)　·　[设计决策](#decisions)

v0.6.0 的试玩主线是六区首杀收集纹章，再到镜室亲手点灯。下文保留早期原型的设计决策。[当前点灯规则](features/lighthouse/design.md)

昨夜风暴掀翻了塔顶的储油罐。到了黄昏，灰湾村的渔人还在按旧习惯等那束光。直到雾里的东西爬上晒网架，守塔人的学徒才提着一盏油灯走出村口。玩家要找回塔门钥匙，重启供油机，亲手把光投回海面。

## 玩家的一趟出行

从铁匠铺门口能看见东边岬角上的塔顶。出村时，玩家选一个能认出的地标作目的地。白天可以循河声摸到泵站，黄昏则要看潮位和余油，决定继续深入、抄近路，还是带着材料回村。

一次典型的抉择发生在退潮的沙滩上。沉船的舱门就在眼前，身后的影兽却在逼近。举灯能逼退它，也会烧掉返程用的油。玩家可以趁空隙进船，或记住桅杆的位置，先沿高岸回家。

## 这款游戏要做成什么样

**探索有凭据。** 高位第三人称 3D 单人动作冒险，面向喜欢认路、愿意打短仗的玩家。河流、火山口和塔影给方向，小地图留住玩家已经找到的路。

**战斗有空隙。** 让玩家在少量敌人之间腾出空间。击倒一只怪、驱走一只怪、带着油桶顺利离开，都可以是一次遭遇的好结果。

**回村有变化。** 铁匠把这趟带回的材料做成下次用得上的装备。沿路救下的渔人会重新挂网，终局的灯光最终扫过这些熟悉的人和地方。

## 首版范围

首次普通游玩目标约 3 小时。使用 PC 键鼠。摄像机跟在角色身后高处，鼠标调节朝向与俯仰，靠近遮挡物时自动收近。地图手工布置，集中制作一座岛、一座村庄和一场塔顶决战。下文的耗油、时长、配方与战斗数值均为原型试玩起点。

[ASSUMPTION] PC 单人键鼠为首版平台。原型使用 Godot 4.6.3，引擎工程与 Windows 试玩说明见仓库首页。

## Decisions

| 编号 | 首版选择 | 设计依据 |
| --- | --- | --- |
| D-001 | 三处油库任选两处。 | 玩家可凭路线、装备和潮位做取舍，支持约三小时的首玩节奏。 |
| D-002 | 塔用燃料单独封装，随身提灯使用灯油。 | 夜里多举一次灯只改变这趟行程的风险，已经取得的主线进度可保留。 |
| D-003 | 摄像机跟在角色身后高处，支持鼠标转向与俯仰。 | 举灯时保持怪物在角色正面，探索时可以抬头辨认地标。 |
