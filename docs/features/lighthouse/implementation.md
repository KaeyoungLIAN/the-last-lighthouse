# 六区纹章与终局的试玩版实现

每位区域首领的死亡事件带有地区 ID。远征遭遇系统据此发出首杀通知，游戏登记该地区的纹章并写入航程存档。塔门用六个有效地区的获得情况判断是否开放。灯芯的 E 交互会写入通关标记，随后播放镜室到海岸的结局过场。[远征遭遇](../../../game/expedition_encounters.gd) · [主线](../../../game/main.gd)

v0.6.0 把新进度写入单独的航程文件，优先读当前快照和备份，再回退到远征旧档及最早的岛屿旧档。已通关的旧档保持原有结局。旧镜室内未集齐六章的未通关角色在塔外恢复，保留已获的有效纹章和装备。[航程记录](../../../game/journal.gd)
