# 六区纹章与点灯结局

## 当前试玩规则

三幕序章交代了学徒的身份、礁外渔船的处境和纹章点灯的目标。学徒可以前往任意区域。玩家可以自己标记猎场、首领或村里的去处。每位区域首领首次被击败时，结算该区独有的一枚纹章并存档。集齐后返回望潮岬。回访已征服的区域时，相应纹章继续提供当地护佑。

六种纹章集齐后，玩家在望潮岬塔门按 E 直接进入镜室。玩家可以走下出口台阶，也可以走到灯芯前按 E。第一次点灯时立即记录旅程完成。镜室先显示六枚纹章被点亮，随后镜头转向海上的光束，进入结局。点灯后保留所有已获纹章，继续探索时继承各区护佑。

旧版已经点亮灯塔的旅程保留结局标记和原有纹章。旧版尚未通关、停在镜室而纹章未齐的旅程从塔外继续。沉船、泵站和冷却窑的修船物料用于码头的独立委托，港灯随主灯点亮。

## 灯塔内部与守护者

钥匙拧开望潮岬的铁门。塔内的老守护者仍在转动镜架，影子黏在它背上。玩家要让灯光照穿那层影，才能靠近塔顶的灯芯。

### 从门厅到镜室

门厅墙上挂着守塔人的值班册，图示把两只封装油罐接入供油机。可分次存入，面板显示 0/2、1/2、2/2。满两罐后平台升到镜室。塔门永久开启，缺罐时可以随时回岛寻找。

楼梯间先放一只贴墙的影兽和一面固定镜。拉下铜柄让一道灯光扫过黑壳，露出白色裂纹。通过后抵达塔顶休息台，可存档、补满灯油，推门才开始战斗。

| 战斗阶段 | 看见或听见的预告 | 可以做的事 |
| --- | --- | --- |
| 上半场 | 守护者提起长柄，地面出现弧形擦痕，随后横扫。 | 闪过柄端，举灯照背部 1 秒，使影壳张开 3 秒，近身出刀。也可拉镜柄照破影壳。 |
| 半血转场 | 守护者压低身形，镜座依次发出咔哒声，地上亮出下一道光带。 | 穿过已扫过的区域，抵达下一面镜。光带形状和声响在楼梯间已经出现过。 |
| 下半场 | 两只影兽从镜后爬出。守护者沿亮纹冲刺，撞上镜座后停顿。 | 举灯赶开影兽，或引它们进入镜光；让冲刺落空后，借镜光破壳，继续近击，直到守护者生命耗尽。 |

场边镜架由已启动的供油机驱动，可反复拉动，空油也能破壳。重试从塔顶休息台开始，已安装的油罐、已开的门和升降平台全部保留。

### 最后一次交互

守护者跪下后让出灯芯。玩家走上最后一级台阶，按住交互杆，由自己把光束转向村庄。光先掠过河口，再照到铁匠的窗户；开场获救的渔人推开栅门，夜里的东西退回林线。镜头停在重新亮起的塔上，保存通关记录。

## 第一轮原型与试玩判据

先用村口、林道、潮滩岔口和一间镜室搭出一趟可玩的往返。玩家出发前为什么点灯，返程时为什么收灯，是本作最先要通过试玩回答的问题。

### 分三次扩大可玩范围

**灰盒往返。** 用基础几何做村口营火、林道、常通高岸和潮路。放入一只惧光怪、一罐燃料和铁匠工作台，让一次采料、战斗、返村和换装都能走通。

**全岛探索。** 接入镜湖水系、火山、三处燃料点、森林钥匙、小地图与昼夜潮钟。检查玩家是否会依据潮位和余油调整路线。

**灯塔终局。** 接入镜室教学、两阶段 Boss、点灯交互和村庄反馈，再用首次玩家的通关记录调整三小时预算。

### 首轮试玩记录

| 学习重点 | 观察方法与通过条件 |
| --- | --- |
| 场景探索 | 让首次玩家自行找塔并完成任意两个燃料点。记录迷路的分岔与停留时间；三种燃料组合在涨潮时都应可从村出发并返回。 |
| 资源管理 | 让玩家在夜里耗尽灯油。应能沿路标回到火盆，继续补给；尝试锻造与补油后，任务油罐数量应只随拾取或提交改变。 |
| 战斗与光照 | 记录首次举灯时长、敌人退缩和开始挥刀的时机。遮住提示文字后，玩家仍应能说出苔影犬与寄壳蟹对光的不同反应。 |
| Boss 设计 | 以初始短刀、空灯壶完成一次镜架破壳并取胜。战败后重试，门锁、供油与升降平台均应保持已解锁状态。 |
| 游戏时长 | 邀请 5 名首次玩家，记录出村、取钥匙、第二罐入手、进塔和点亮时间。以通关中位数 150–210 分钟为首轮目标，单独记录等待潮位和重复跑图的耗时。 |

若三个燃料点的抵达时间明显短于预算，先复核探索时长目标。若时间主要耗在等潮，优先让高岸入口更醒目；若玩家整场举灯，先调整威胁出现的位置和灯光反馈，再动耗油速度。把时间留给新发现、备战选择和一场看得懂的决战。
